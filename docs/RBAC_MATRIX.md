# 工装管家 RBAC 权限矩阵与验收清单

## 角色与数据范围

| 模块 | 老板 `owner` | 项目经理 `project_manager` | 财务 `finance` | 业务 `business` |
| --- | --- | --- | --- | --- |
| 用户、角色、停用、重置密码 | 全部 | 禁止 | 禁止 | 禁止 |
| 线索、跟进、赢单 | 全部 | 禁止 | 禁止 | 仅 `leads.owner_user_id = auth.uid()` |
| 项目基础 | 全部 | 仅 `project_members` 已分配项目，可更新 | 全部只读 | 仅本人赢单项目摘要只读 |
| 里程碑、BOM、工单、日报 | 全部 | 已分配项目可管理 | 必要成本只读 | 禁止 |
| BOM 成本、机械费、成本发票 | 全部 | 已分配项目可管理 | 全部可管理 | 禁止 |
| 合同、回款、发票、费用、利润 | 全部 | 已分配项目只读履约信息 | 全部可管理 | 禁止直接读取；项目表仅提供合同金额摘要 |
| 材料、人工价格库 | 全部管理 | 只读 | 只读 | 禁止 |
| 系统设置、操作日志 | 全部 | 禁止 | 禁止 | 禁止 |

## Edge API 路由矩阵

- 公共：`GET /api/health`、`GET /api/auth-config`。
- 所有启用账号：`GET /api/me`。
- 老板：所有现有 API，并独占 `/api/users*`。
- 项目经理：`projects`、`alerts`、`milestones`、`project-files`、`work-orders`、`labor-reports`、`bom-*`；合同/财务/价格 API 仅 GET。
- 财务：合同、回款、发票、费用、利润 API 全部；项目、日报、价格 API 仅 GET；BOM 成本/机械费/成本发票可写。
- 业务：`leads`、`lead-notes` 全部；仅 GET 本人的 `/api/projects` 与 `/api/projects/{id}/detail` 摘要。
- 任何不在角色矩阵内的已认证请求：`403 {"error":"无权执行此操作"}`。
- RLS 再按 `auth.uid()`、`project_members`、线索/项目 UUID 归属执行行级限制；Edge 允许不代表能越过 RLS。

## 可重复验收清单

对四类账号分别执行，测试数据使用 `RBAC-TEST-<时间戳>` 前缀，结束后由老板删除：

1. 登录：正确密码成功；错误密码失败；页面没有注册入口。
2. 身份：`GET /api/me` 返回真实姓名、英文角色和中文角色。
3. 会话：刷新浏览器后仍登录；access token 刷新后 API 继续成功。
4. 菜单：只显示本角色允许的菜单；只读页面不显示新增、修改、删除、审核等按钮。
5. 读取：允许模块返回 200；行数只包含本人线索或已分配项目。
6. 新增、修改、删除：在每个角色的可写模块分别完成一次，并刷新确认持久化。
7. 越权：直接构造被禁止模块请求，必须返回 403；不能只以菜单隐藏作为通过依据。
8. 项目越权：项目经理 A 请求未分配项目，数据库不得返回数据或允许写入。
9. 业务越权：业务 A 请求业务 B 的线索，数据库不得返回数据或允许写入。
10. 财务边界：可管理合同/回款/发票/成本，不能调用用户管理、线索写入或系统设置。
11. 停用：老板停用测试账号后，旧会话不能继续调用业务 API。
12. anon：不带 Bearer token 的业务 API 返回 401；直接 PostgREST 访问 public 表无数据权限。
13. 日志：Edge Function 无新增 500；RLS/GRANT 失败应表现为 403，而不是泄露数据库错误。
